# Public Retail Benchmark

Benchmark: M5 Forecasting - Accuracy
Source: Kaggle / University of Nicosia
Dataset: Walmart retail unit sales
Purpose: External validation of the demand forecasting pipeline

Source page: https://www.kaggle.com/competitions/m5-forecasting-accuracy/data

Note: The benchmark is subject to the competition rules. The project uses it for external evaluation and does not redistribute the original dataset.
